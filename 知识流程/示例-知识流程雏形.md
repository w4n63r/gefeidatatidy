# 示例｜内容驱动的"知识流程"雏形（7 篇代表文章实测）

> 这份文件是**演示样张**：证明"逐篇读 HTML 内容 → 提炼知识流程（先学什么、再学什么）"这个方法是可行的、且比看文件名靠谱得多。
> 下面每一篇的"内容讲什么/教了什么/前置知识"都来自**我实际读了文章正文**后的分析，不是猜的。
> 完整版由《02-执行手册》对全部 726 篇逐篇分析后生成（产出在 `知识流程/知识流程.md` + 流程图）。

## 一、7 篇代表文章逐篇分析

### 1. 《把工作当做自己的作品》（2020-04-14，认知/心态）
- **内容讲什么**：热爱工作、把工作当作品打磨；想法太多不如静下心做好一件事；用"一个查询页面线上变慢→定位 COUNT/分页慢→优化 SQL"的例子讲什么叫认真做事。
- **教了什么**：心态上要"长期主义 + 把每件事做透"；遇到问题先找根因再解决。
- **前置知识**：无。
- **难度**：★（入门必读）
- **属于阶段**：第 0 阶段·认知与心态

### 2. 《出海四个月月入万刀：Fiona 说新手先找鱼多人少的池子》（2026-07-23，选品/找方向）
- **内容讲什么**：新手做海外站第一步不是"我能不能做出来"，而是**先找池子**——鱼多（有需求、有人花钱验证）、人少（竞争还没到打不动的程度）；怎么找：跟着高手学"痕迹"（外链路径、新增内容、页面结构），通过鱼找人，不要和大佬正面硬刚。
- **教了什么**：一套可执行的选方向方法（先确认池子里有鱼→再看人多不多→用"有人花钱"验证需求）。
- **前置知识**：无（但最好先有第 0 阶段的心态）。
- **难度**：★★
- **属于阶段**：第 1 阶段·选品与找方向

### 3. 《如何 10 分钟上线一个 AI 导航网站？》（2023-04-21，快速建站）
- **内容讲什么**：不买服务器不找框架，**徒手 HTML + GitHub + Vercel** 上线；用 ChatGPT 帮忙生成页面代码；域名可以用闲置的或 Vercel 免费域名。
- **教了什么**：最快最小成本上线一个网站的完整动作（建仓库→写页→部署→绑域名→自动更新）。
- **前置知识**：懂基本 GitHub 操作即可，不会 HTML 也行（ChatGPT 帮忙）。
- **难度**：★（第一个动手练习就做这个）
- **属于阶段**：第 2 阶段·快速建站与开发

### 4. 《新上线的网站，如何快速让谷歌收录？》（2023-07-02，SEO 收录入门）
- **内容讲什么**：新站快速收录的实操：去 V2EX 发帖留链接；用动态页面生成大量关键词页（例：16 进制颜色码可生成一千多万个页面）；靠**内链 + sitemap** 让搜索引擎发现；"一个页面 10 访问 × 10 万页面 = 每天百万访问"的思路；以及"第一个产品做周末能做完的小网站，用 ChatGPT 都能做"。
- **教了什么**：收录原理 + 海量页面思路 + 小步快跑的产品观。
- **前置知识**：会建站（对应上面第 3 篇）。
- **难度**：★★
- **属于阶段**：第 3 阶段·SEO 与流量（入门）

### 5. 《3 个月花掉 30 万美金外链预算：Andy 讲 SEO 增长的学费》（2026-07-30，SEO 进阶/顺序方法论）
- **内容讲什么**：90 天花 30 万美金做 AI 产品 SEO，DR 30→71、自然流量翻 100 倍。最值钱的不是预算，是**顺序**：技术和品牌是"1"（robots/sitemap/canonical/首屏速度等先抓最有效的 5%），其他都是"0"；内容要能留下资产（先表达诚意再放量）；最后才是外链和 PR。
- **教了什么**：做 SEO 增长的**正确顺序**：技术底子 → 品牌信任 → 内容资产 → 外链放大；新站别一上来纠结复杂策略。
- **前置知识**：先懂收录/关键词（第 3 阶段），否则"顺序"无从谈起。
- **难度**：★★★
- **属于阶段**：第 4 阶段·SEO 进阶与增长

### 6. 《从网站被罚到月入 3 万美金：刘屹讲他交过的学费》（2026-08-03，避坑警示）
- **内容讲什么**：选卷赛道（好行业第 10 名 > 烂行业第 1 名）→ 找细分位置；然后是一串学费：**① 批量上页面把网站做废**（AI 批量堆内容→用户秒退→整站被罚→流量清零）；**② 推广不够聚焦**（SEO/Reddit/短视频同时做都做不好，要拆购买路径）；还有支付账号出问题、太早见 VC。
- **教了什么**：别人能做 ≠ 你现在能做；**阶段错了，动作就会变形**；批量页面要先凑齐关键词真实性、页面质量、站点基础、发布节奏；推广要聚焦一条链路。
- **前置知识**：先学过第 3-4 阶段的 SEO 基础，才能理解"批量页面的坑"。
- **难度**：★★★（建议放到中后期学，配合避坑复盘）
- **属于阶段**：第 5 阶段·避坑警示（贯穿，但系统复盘放最后）

### 7. 《邮件越堆越多，他做了个整理工具，月入超 1 万美元》（2026-07-15，产品/变现）
- **内容讲什么**：Inbox Zero 的案例——给自己做工具解决真实痛点；关键产品决策：**不换邮箱、只补一层**（用户不用搬家），把"分类/退订/待回复提醒/起草回复"做深；价值具体、容易理解。
- **教了什么**：选品+产品设计的范例（先解决自己的痛、不挑战用户习惯、单点做深）；变现路径（订阅制工具站）。
- **前置知识**：第 1 阶段（找需求）和第 2 阶段（能上线）。
- **难度**：★★
- **属于阶段**：第 1/5 阶段（选品案例 + 变现案例）

## 二、从内容里提炼出的"知识流程"（先学什么，再学什么）

```
第0阶段 认知与心态 ── 把工作当作品 / 先躬身入局 / 长期主义
   │
   ▼
第1阶段 选品与找方向 ── 先找"鱼多人少"的池子 / 用"有人花钱"验证需求
   │                / 跟着高手学痕迹（外链、新增内容、页面结构）
   ▼
第2阶段 快速建站 ── 10 分钟上线：GitHub + Vercel + ChatGPT / 周末 MVP
   │
   ▼
第3阶段 SEO 收录入门 ── 新站怎么被收录 / 内链+sitemap / 关键词页思路
   │
   ▼
第4阶段 SEO 进阶与增长 ── 顺序：技术+品牌(1) → 内容资产 → 外链放大
   │                   / 先抓最有效的 5% / 先表达诚意再放量
   ▼
第5阶段 变现与收款 ── 订阅/广告/联盟 / Inbox Zero 式"补一层"产品
   │
   ▼
第6阶段 规模化与团队（数据里有更多文章，全量分析后补齐）
```

**避坑警示不是单独一章，而是贯穿全程**，但建议在学完第 3-4 阶段后**系统复盘**一次：
- 刘屹的教训：阶段错了动作就变形；批量页面要先凑齐条件；推广要聚焦一条链路。
- Andy 的教训：顺序错了，花钱只是交学费。

**这套顺序为什么合理（内容依据）**
1. Fiona 文里明确说"不要一上来就问我技术能不能做出来，先问池子里有没有鱼"→ 选品要先于动手。
2. 第 3 篇（收录）默认你已经会建站（作者在文里直接教建站）；第 4 篇（增长顺序）默认你懂收录。
3. 第 6 篇（避坑）里的坑（批量页面被罚）只有你先做过收录/页面，才能真正理解 → 放中后期。
4. 第 7 篇（变现案例）是"选品+产品"的完整闭环 → 放在选品和建站之后当范例。

## 三、这说明什么

- 看**文件名**只能分出"SEO/出海/AI"这类大标签，看不出**先后关系**；
- 只有**逐篇读内容**，才能发现"选品要先于建站、技术+品牌要先于外链、避坑要在学完基础后复盘"这种真正的知识流程；
- 这就是《02-执行手册 v3》的核心：**阶段3 全量逐篇分析 → 阶段4 知识流程构建**。
