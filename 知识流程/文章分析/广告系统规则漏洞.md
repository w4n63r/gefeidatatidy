# 互联网广告系统的规则漏洞 - Rule Holes in Ad Systems

## Core Summary

> [!abstract] TLDR
> 广告平台刚上线时常有规则漏洞，找到漏洞就能超低价拿到大量曝光；本文科普广告系统（RTB/SSP/DSP/ADX）如何运转，并用真实案例讲"出价与预算"漏洞和"素材MD5"作弊。
>
> - **架构**：SSP（卖流量）→ ADX（撮合）→ DSP（买流量），按曝光实时竞价（RTB）、二价收费
> - **漏洞1**：出价可设很高、预算设很低 → 大量竞价成功却只扣预算内的钱（薅羊毛）
> - **漏洞2**：素材按 MD5 判重，改一个像素/换LOGO位置即可绕过限制继续投放
> - **结论**：规则漏洞源于产品经理/开发不懂广告业务；攻防循环让系统越来越完善

```
│   ├── ADX 撮合平台（RTB实时竞价，二价收费）

│   ├── 出价高+预算低 → 大量曝光只扣预算
│   ├── 已消耗≥预算后 +1元 → 再获大量曝光
│   └── 素材改MD5 → 绕过同素材限量
└── 本质
    ├── 不懂广告业务的技术/产品引入漏洞
    └── 攻防循环 → 系统越来越完善
```

## Theme Analysis

### Theme 1: Ad Ecosystem 广告生态

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 角色分工 | 流量、撮合、买量三方各司其职 | SSP/ADX/DSP 定义清晰，RTB 按曝光实时竞价 |
| 计费机制 | 二价收费、按曝光/点击/效果出价 | "ADX 按二价也就是第二高的价格收费" |
| 数据回传 | oCPA 按注册/付费成本出价，需上报转化 | "当发生注册或付费时，你需要上报转化数据给ADX" |

> [!tip]- Top 3 Actionable Recommendations
> 1. **投放前懂生态**：做广告投放前先搞清 SSP/ADX/DSP、二价、oCPA，避免被"低价曝光"话术迷惑
> 2. **警惕异常低价**：遇到"超低价大量曝光"先怀疑是漏洞还是骗局，漏洞会被快速堵上，不可持续
> 3. **做产品防漏洞**：如果你做广告/交易类产品，把"出价与预算关系""素材判重"当必测项

### Theme 2: Rule-Hole Attack-Defense 漏洞攻防

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 漏洞根因 | 业务理解不足引入漏洞 | "大多数是由不懂广告业务的技术在开发时引入的" |
| 攻防演进 | 堵一个漏一个，系统逐渐完善 | 出价限制→预算+1元→概率不竞价，来回攻防 |
| 素材作弊 | MD5 判重可被轻易绕过 | "加一个像素点、改变LOGO位置……改变文件MD5值" |

> [!warning]- 提醒
> 本文是**科普向**的旧文（2019），具体漏洞早已被堵；价值在于理解广告生态的底层机制，不要试图照搬"薅羊毛"。
