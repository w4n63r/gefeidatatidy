# 第0步：零基础前端入门 - Step 0: Frontend Basics from Zero

## Core Summary

> [!abstract] TLDR
> 零基础学前端做网站的路径：**B站 28.5 分钟 HTML+CSS 入门视频（不学 Vue/React）→ 2 周学会徒手写网页 → 学原生 JS 基础（MDN 当手册）→ 做出"在线闹钟"=入门**。目的=做站赚钱，不是找前端工作，用到什么学什么。
>
> - **入门**：只看 HTML+CSS 的 28.5 分钟视频（第一遍看、第二遍跟着做）
> - **JS**：MDN 当手册，学事件用法即可
> - **入门标准**：做出可交互的"在线闹钟"网页
> - **别学 Vue**：至少做 3 个原生网站再说；月入 25 万美元的 Levels 还在用 PHP+jQuery
