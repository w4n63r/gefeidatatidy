# 看得上小钱，才能赚大钱 - Start with Small Money

## Core Summary

> [!abstract] TLDR
> 别像狗熊掰棒子一样总想找"最大的"，**先抓住眼前能赚的小钱，从第一块钱赚起**。用巴基斯坦哥们的故事展示"赚钱能力是升级打怪"：PHP 外包→WordPress 建站→卖插件→收购插件→钱生钱→年入千万美金。
>
> - **升级路径**：出卖时间→做站→插件（一份时间卖多次）→收购（投资决策时间）→钱生钱
> - **认知**：只有赚了很多小钱，才可能领悟赚大钱的诀窍
> - **迁移**：万兴科技=做软件+收购赚钱软件上市；对个人=先做第一个站、赚第一笔 Adsense 广告费=入门
> - **金句**：不积跬步，无以至千里；不积小流，无以成江海
