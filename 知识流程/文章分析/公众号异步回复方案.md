# 公众号异步回复方案 - Async Reply for WeChat Official Account

## Core Summary

> [!abstract] TLDR
> 公众号接对话能力的异步回复方案：5 秒同步响应限制 + 客服消息（48 小时内可主动发）配合消息队列，实现"先回 SUCCESS、后台慢慢生成、再推送给用户"。
>
> - **限制**：5 秒内不响应（3 次）→ 提示"暂时无法提供服务"
> - **方案**：收到消息 → 入队 → 立即回 SUCCESS → 常驻进程读队列 → 调模型 → 客服消息发结果
> - **细节**：长文分段发送、发送"正在输入"状态减缓焦虑、支持图片/语音/图文等多种消息

## Theme Analysis

> [!tip]- 核心可迁移点
> 1. **异步化架构**：同步接口先快速应答、后台慢慢处理、再主动推送——任何"AI 回复慢"的场景都适用（网站/工具站同理）
> 2. **队列解耦**：请求→队列→worker 处理，避免阻塞
> 3. **体验细节**：发送"正在输入/处理中"状态，能显著降低用户等待焦虑
