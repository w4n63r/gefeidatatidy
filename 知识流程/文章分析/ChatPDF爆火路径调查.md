# ChatPDF 爆火路径调查 - How ChatPDF Reached 5.4M Visits

## Core Summary

> [!abstract] TLDR
> ChatPDF（智能文档问答）爆火路径：**1/2 注册域名 → 3/2 赶在 GPT chat API 发布次日上线 → 3/4 中文互联网电报群首发 → 3/5 爆火+被墙 → 13 日上线 5 美元/月套餐 → 6 月开放 API**。流量 65.8% 直接访问（口口相传）+22.1% 搜索。
>
> - **时机**：抓住 GPT chat API（3/1）发布窗口，次日上线
> - **传播链**：开发者推特→电报/微信→社交平台→科技媒体
> - **变现**：5 美元/月订阅（2000 页）、开放 API
> - **启示**：技术已成熟，第一个做成产品的人吃到口口相传红利；可用 ChatPDF API 快速包装产品
