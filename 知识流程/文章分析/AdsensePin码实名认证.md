# Adsense Pin 码与实名认证 - AdSense PIN & Identity Verification

## Core Summary

> [!abstract] TLDR
> Adsense 赚满 10 美元后，谷歌从美国寄**平信**（含 Pin 码）验证实人实地；收不到时：凑满 3 次重发 → 申请人工审核 → 上传"身份证照片 + 地址地标合影"通过。
>
> - **流程**：满 10 美元 → 谷歌寄平信 → 填 Pin 码 → 开始提现
> - **收不到**：每次提示寄出两周后可再点重发，凑 3 次进人工审核
> - **人工审核材料**：身份证照片 + 你站在填写的地址地标旁的照片（人和地标同框）
> - **经验**：按方法提交，有朋友当天提交次日通过

## Theme Analysis

### Theme 1: 提现前必经关卡

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 平信机制 | 美国平信、丢失率高 | "毕竟是美国邮寄过来的信件，丢失率有点高" |
| 三次重发 | 凑满 3 次才能人工审核 | "一般要求连续发送3次信件都没法收到后，才可以进入人工申请" |
| 材料要点 | 身份证+地标合影 | "上传身份证照片和你自己在你填写的地址旁边的地标旁拍摄的照片" |

> [!tip]- Top 3 Actionable Recommendations
> 1. **盯紧后台**：提示信件寄出后两周就去看能否"再次发送"
> 2. **收件地址填能收到的**：用可收信地址（如可代收的私人地址），降低丢失率
> 3. **人工审核备好材料**：身份证 + 地址地标合影（同框），一次过
