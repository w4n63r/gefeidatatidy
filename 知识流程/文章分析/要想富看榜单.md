# 要想富，看榜单 - Find Demand by Reading Rankings

## Core Summary

> [!abstract] TLDR
> "要想富，看榜单"：**Similarweb 行业排行榜（210 个行业×300 个网站，去重约 6.3 万）→ 筛选"自然搜索流量占比高"的站 → 逐个分析它满足什么需求、你能不能分一杯羹**。原则：**大市场找大需求做小产品，别去小市场找小需求**（做到头部也赚不多）。
>
> - **方法**：下载全行业榜单→去重→按自然搜索占比筛选→逐个分析
> - **原则**：大市场大需求→小产品分杯羹；小市场小需求→头部也赚不多
> - **案例**：谷歌插件市场>Edge 插件市场（回大市场）
> - **执行**：哥飞送社群排行榜文件可直接分析

## Theme Analysis

### Theme 1: 看榜单找需求

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 榜单即需求 | 能上榜=满足某种需求 | "能上榜的产品就代表着能够满足某些需求" |
| 筛选标准 | 自然搜索占比高 | "重点筛选出大部分流量来自于自然搜索的网站" |
| 逐个分析 | 看它怎么满足需求 | "网站到底做到是什么，满足了什么需求，为什么能够拿到那么多的自然流量" |

> [!tip]- Top 3 Actionable Recommendations
> 1. **下载行业榜单**：Similarweb 全行业榜单，去重筛选自然搜索占比高的站
> 2. **逐个拆解**：每个站"满足什么需求→你能不能做"
> 3. **选大市场**：大市场找大需求做小产品，别在小市场卷

### Theme 2: 原则

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 大市场分杯羹 | 不难 | "大市场里找到大需求，你做个小产品，分一杯羹……是不难的" |
| 小市场陷阱 | 头部也赚不多 | "最怕的是你去小市场里找小需求，即使你做到了头部，也赚得不多" |
| 回大市场 | Edge 不如谷歌 | "还是回到谷歌插件市场来吧" |

## PACER Application

> [!important] PACER Classification: P — Procedural
> **Rationale**: 可执行的找需求方法，属程序性知识

### Digest Actions

1. **拿榜单**：Similarweb 下载 5 个你感兴趣行业的 TOP 榜
2. **筛选**：留下"自然搜索占比 >50%"的站
3. **分析**：逐个看它们满足什么需求、你能做什么
4. **记录**：建"榜单→需求→产品"清单
