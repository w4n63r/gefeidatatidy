# 用 Google Trends 判断新词 - Find New Keywords via Google Trends

## Core Summary

> [!abstract] TLDR
> 用 **Google Trends** 免费判断关键词出现时间：**新词=出现时间不超过 12 个月的词**。例：ChatGPT 的词首次出现在 2022-11-30（上线当天）、Grok 在马斯克宣布后上升。可多词对比看热度差异。
>
> - **方法**：Google Trends 输入词 → 时间设长（如 2022-01 至今）→ 看首次有搜索量的时间
> - **定义**：出现 ≤12 个月=新词
> - **案例**：ChatGPT 11/30 出现、Grok 11/4 上升
> - **对比**：多词同图对比（ChatGPT vs Grok）
