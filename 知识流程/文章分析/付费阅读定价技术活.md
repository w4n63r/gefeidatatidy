# 付费阅读定价是个技术活 - Pricing Is a Craft

## Core Summary

> [!abstract] TLDR
> 用"平均每个在看价值"这个指标来思考付费阅读定价：三表（1元/3615元/在看价值5.83）、Caoz（3元/2388元/23.18）、小道消息（8元/2712元/39.88）——薄利多销 vs 高价低量的取舍。
>
> - **指标**：付费数≈阅读数；用收入÷在看数算"每个在看价值"
> - **数据**：定价越高单价越贵，但绝对收入未必更高（三表靠低价+首发流量拿了最高收入）
> - **结论**：定价是技术活，需要持续收集数据验证

---

## Mind Map

```
付费阅读定价
├── 数据口径
│   ├── 付费数 ≈ 阅读数（没付费=没读完）
│   └── 平均每个在看价值 = 收入 ÷ 在看数
├── 三组样本
│   ├── 三表 1元 → 3615元 / 620在看 / 价值5.83
│   ├── Caoz 3元 → 2388元 / 103在看 / 价值23.18
│   └── 小道消息 8元 → 2712元 / 68在看 / 价值39.88
└── 结论：薄利多销 vs 高价低量，要看总收益
```

## Theme Analysis

### Theme 1: Pricing & Conversion 定价与转化

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 价格带 | 三档定价对应不同转化率 | 1元→3615付费；3元→796；8元→339 |
| 收入对比 | 绝对收入：薄利多销反而最高 | 三表 3615 > 小道消息 2712 > Caoz 2388 |
| 单位价值 | 单价越高、每个"在看"越值钱 | 5.83 / 23.18 / 39.88 |

> [!tip]- Top 3 Actionable Recommendations
> 1. **先定指标**：为你的付费产品定义一个"单位价值"指标（如收入÷付费人数、LTV）
> 2. **做价格测试**：同一内容试 1/3/8 元三档，看总收益而非单价
> 3. **注意样本偏差**：三表的"首发效应+低价"让数据失真，别急着下结论

### Theme 2: 数据验证思维

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 样本不足 | 3 篇数据说明不了大问题 | "目前我仅收集了三篇付费文章的数据" |
| 持续追踪 | 多收集几天数据再下结论 | "等几天再看看，多收集一些数据后，再来分享" |

### Digest Actions

**Key evidence worth storing**:
1. 1元定价 + 首发流量 → 3615 元（薄利多销有效但样本特殊）
2. 8元定价 → 339 付费，单位在看价值最高（39.88）
3. 定价高低 ≠ 收入高低，总收益才是结果

**Storage recommendation**: 存入"定价"主题笔记，作为你设计订阅/付费产品时的参考案例。

**Review method**: 下次定订阅价格时，用"单位价值 × 转化率 × 目标人数"重算一遍。
