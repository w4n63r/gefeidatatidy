# 养网站防老第5步：内页与内链建设 - Inner Pages Development & Internal Linking Strategy

## Core Summary

> [!abstract] TLDR
> 养网站防老官方教程第 5 步：全面展开内页制作与站内权重传递链路建设——优化首页 TDK 与标题属性、为每个内页配置独立长尾 TDK/H1、用原生 JS 实现功能逻辑，并通过 Semrush 拓展相关词 H2 段落与双锚文本内链实现主副词权重深度传递。
>
> - **首页内链与 Title 优化**：在首页 Logo、导航栏与各国家 section 中，全部为 `<a>` 标签补充包含关键词的 `title` 属性
> - **双锚文本精准传递权重**：首页对每个国家内页分别提供 `[Country] Phone Number Generator` 与 `Generate [Country] Phone Number` 两个入口，向内页传递不同核心词权重
> - **内页原生 JS 功能闭环**：在内页第 2 个 section 编写纯原生 JavaScript 号码生成算法，实现免后端调用的即时交互
> - **Semrush 拓展 H2 内容矩阵**：基于 Semrush 导出的长尾词（如 format, code 等），在功能下方由 AI 生成多个垂直 H2 section 增强内容厚度

## Theme Analysis

### Theme 1: Internal Linking & Anchor Text Strategy 站内内链架构与双锚文本策略

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 锚文本多样性 | 同一目标页面使用不同词根的锚文本链接，同时覆盖多个搜索变体 | 首页对每个内页各放 2 个链接：“xxx Phone Number Generator” 与 “Generate xxx Phone Number” |
| Title 属性强化 | 为所有站内链接补全描述性 `title` 属性，增强爬虫对链接目标的理解 | `<a href="..." title="China Phone Number Generator">` |
| 首页权重大盘布局 | 首页 Title 罗列核心目标国家，成为全站聚合与权重集散中心 | `<title>Phone Number Generator, China, India, US...</title>` |

> [!tip]- Top 3 Actionable Recommendations
> 1. **双锚文本交叉链接**：在列表页或首页对核心内页同时部署“名词型”与“动词型”双锚文本
> 2. **Semrush 拓展内页 H2**：严禁内页仅放一个按钮成为单薄页面，必须补充 3-5 个 H2 展开格式、规范与常见问题
> 3. **客户端纯 JS 降本**：轻量计算型工具优先采用纯前端 JS 算法，零服务器请求成本支撑海量并发
