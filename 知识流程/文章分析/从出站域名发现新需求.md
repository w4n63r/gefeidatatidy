# 从出站域名发现新需求 - Find New Products via Outbound Domains

## Core Summary

> [!abstract] TLDR
> 用 Semrush 查高流量网站的**出站域名**（外部链接指向），就能发现"正在推广的新产品/新网站"：新站在推广时必然到处留链接，顺着链接就能找到它们。
>
> - **源头**：vc.ru / pikabu.ru 等高权重站出站链接 → 大量新站
> - **批量筛选**：查出站域名 → whois 看注册时间 → Similarweb 看流量 → Archive 看收录 → 按条件筛选（7月新注册+被收录+有流量）
> - **价值**：研究需求、分析竞对；甚至可做成"新品监控服务"卖给开发者
> - **原理**：新站推广必留链接 → 出站域名=新品雷达

## Theme Analysis

### Theme 1: 链接即情报

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 推广痕迹 | 新站推广必留外链 | "这些新网站需要去各个地方宣传推广，那么就一定会留下链接" |
| 数据组合 | 多个工具拼出完整画像 | whois+Similarweb+Archive+谷歌API |
| 筛选条件 | 新域名+被收录+有流量 | "查询7月份注册的新域名，谷歌收录了的，Archive收录了的，流量大于多少的" |

> [!tip]- Top 3 Actionable Recommendations
> 1. **学会查"出站域名"**：Semrush 里看大站出站链接，发现别人还没注意的新站
> 2. **建筛选流水线**：把"注册时间+收录+流量"自动化过滤，锁定值得研究的新品
> 3. **反向使用**：分析竞品/同行的出站链接，看他们在哪些渠道推广

## PACER Application

> [!important] PACER Classification: P — Procedural
> **Rationale**: 可执行的需求挖掘方法，属程序性知识

### Digest Actions

1. **实操**：用 Semrush 查 2 个你关注的行业的头部站出站域名
2. **筛选**：列出"新注册+有流量+被收录"的新站 3-5 个
3. **研究**：分析它们做什么、流量哪来、缺什么（你的机会）
4. **记录**：建一个"新品雷达"清单，每周更新
