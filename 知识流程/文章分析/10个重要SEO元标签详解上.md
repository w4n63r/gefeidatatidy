# 10 个重要 SEO 元标签详解（上篇） - 10 Essential SEO Meta Tags: Part 1 - Title, Description & Headings

## Core Summary

> [!abstract] TLDR
> 系统精读了 Search Engine Journal 权威指南中的前三大核心 HTML/SEO 元标签：Title 页面标题（占 15% 排名权重，首置核心词且末尾带品牌）、Description 页面描述（150-160 字符，非直接排名因子但强力决定 SERP 点击率 CTR）、Headings 标题标签（H1~H6 层级结构引导爬虫理解语义与用户预期）。
>
> - **1. Title 标题标签（核心排名支柱，15% 权重）**：
>   - 长度控制在 50~60 字符内，防止 SERP 截断
>   - 核心关键词前置（自然融入），全站页面末尾统一添加品牌名或裸域名后缀
>   - 依托语义理解，一个优质页面标题可广泛命中同义及语序相近的长尾需求
> - **2. Description 页面描述（CTR 转化引擎）**：
>   - 长度控制在 150~160 字符（含空格），自然融入 1~2 个关键句
>   - 包含明确的行动号召（Call to Action，如 Try, Learn, Free），吸引用户点击
> - **3. Headings 标签（H1~H6 结构树）**：
>   - H1 必须存在且每个页面唯一，可与 Title 相同或做语义细化
>   - 避免使用“第一章/第二章”无意义结构，清晰映射页面小节语义，建议全站配备可视化目录

## Theme Analysis

### Theme 1: Core On-Page Header Tags 站内三大核心头部标签最佳实践

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 标题相关性与截断 | 超过 60 字符在 Google 搜索结果中会被省略号截断，损害视觉相关性 | “标题长度保持在 50-60 个字符以内，将重要关键词放在首位” |
| 描述的转化角色 | 虽然 Description 不直接作为排名打分项，但直接影响展示片段与 CTR | “一段良好的描述可以增加点击率，包含最重要的关键词与行动号召” |
| 标题与 H1 协同 | H1 强化页面正文主题，可与 Title 一致，不强制要求差异化 | “Title 和 H1 可以一样也可以不一样，写不出就保持一致” |

> [!tip]- Top 3 Actionable Recommendations
> 1. **全站部署 Title 命名规范**：`[核心功能/页面名称] - [产品品牌/域名]`
> 2. **每个页面手写专属 Description**：确保 150 字符内讲清核心价值并带出核心关键词
> 3. **安装 AITDK / Detailed SEO 插件**：上线前一键体检 Title 长度、H1 数量与 Description 完整度

## PACER Application

> [!important] PACER Classification: P — Procedural
> **Rationale**: 本文为具体的网页头部 Title、Description 与 H1~H6 标签的编写标准与配置 SOP。

### Digest Actions

核心是**站内三大基础标签配置流程**——在所有出海页面的 HTML 模板中固化此规范。

1. **Title 组装**：`${pageKeyword} - ${brandName}`
2. **Meta Description 配置**：`<meta name="description" content="...">`
3. **H1 埋设**：在首屏最显眼位置放置包含关键词的唯一 `<h1>`
