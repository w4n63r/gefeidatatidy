# Semrush 找词陷阱 - Keyword Traps When Using Semrush

## Core Summary

> [!abstract] TLDR
> 用 Semrush Keyword Magic Tool 找"低竞争高搜索量"词时会踩 3 个陷阱：**①季节词（流量不稳定）②谷歌直达（答案/视频直接满足需求，不用做站）③"金矿"词原因不明**。正确姿势：Google Trends 验证全年流量 + 排除导航意图 + 直接搜一下看结果形态。
>
> - **基本方法**：KD 设 0-29（实际建议 21-49）→ 按搜索流量排序 → 排除色情/导航词
> - **陷阱1**：季节词（fantasy football team names 只火一段时间）
> - **陷阱2**：谷歌直达（"how many" 谷歌直接给答案；"half double crochet" 全是 YouTube 视频→适合发视频不做站）
> - **陷阱3**：youtube to mp3 搜索量 612 万 KD 16 却竞争低——金矿还是坑要深究
> - **正解**：Trends 看全年量 + 搜一下看结果页形态 + 建议 KD 21-49

## Theme Analysis

### Theme 1: 三个陷阱

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 季节词 | 流量不稳定=白做 | "这个词只在一年中的某个时间段火，那么就不值得我们花时间去做" |
| 直达词 | 谷歌直接满足=没站机会 | "谷歌的搜索结果直接就能够满足用户的需求了，所以就没必要去做" |
| 形态词 | 结果全是视频→做视频 | "这类关键词……反而适合去Youtube发视频" |

> [!tip]- Top 3 Actionable Recommendations
> 1. **每个候选词过 3 关**：Google Trends 全年量 + 谷歌搜一下看结果形态 + KD 判断
> 2. **看结果页形态再定策略**：全是视频→做视频；谷歌直达→放弃；有站但内页→可做站
> 3. **KD 别设太低**：建议 21-49（0-29 会漏掉好词也容易踩坑）

### Theme 2: 系统化找词

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 碰运气 vs 系统 | 手工输词难找，要系统收集 | "搜集很多别的网站能够拿到搜索流量的词，去重后，一个一个查" |
| 自动化 | 会写插件可自动化 | "如果你会写浏览器前端插件的话，就可以自动化去做了" |
