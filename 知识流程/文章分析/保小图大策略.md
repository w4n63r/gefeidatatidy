# 保小图大：小词起步图谋大词 - Start Small, Aim Big

## Core Summary

> [!abstract] TLDR
> 新手"保小图大"策略：**先做 KD<29、搜索量 10K 左右的小词（新手村攒经验），举全站之力做透**（把用户可能关心的问题解释清楚+内页+二级目录）；小词站稳→扩展兄弟词→再图父词，循序渐进。
>
> - **保小**：新手先做小词（KD<29/10K 搜索），一词一域名，举全站之力
> - **举全站之力**：首页把用户关心的问题解释清楚+每个问题做内页+必要时二级目录（搜索引擎已能读懂文章）
> - **图大**：小词有排名后→加兄弟词→再加父词（域名权重迁移）
> - **重复**：做出几个站走出新手村后，直接注册父词域名，仍从小词做起

## Theme Analysis

### Theme 1: 保小

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 新手村逻辑 | 先打小怪攒经验 | "先在新手村里积累经验，做几个KD小于29的搜索量10K左右的关键词" |
| 举全站之力 | 不是做个单页就行 | "搜索引擎已经进化到可以读懂文章了……让搜索引擎感受到你的诚意" |
| 一词一域名 | 主词域名权重集中 | "最好的办法就是用这个关键词注册一个域名" |

> [!tip]- Top 3 Actionable Recommendations
> 1. **新手先做 3 个小词站**：KD<29 + 10K 搜索量，一词一域名
> 2. **做"厚"页面**：把小词相关的问题都解释清楚，加内页（不是几百字单页）
> 3. **内链回传**：内页/二级目录全部回链首页，集中权重

### Theme 2: 图大

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 权重迁移 | 小词权重给兄弟词/父词背书 | "你的域名已经在小词里有一定权重了，那么对于兄弟词汇，也会更容易接受" |
| 循序渐进 | 小→兄弟→父 | "通过这种循序渐进的方式，你慢慢把父词汇也做上来了" |

## PACER Application

> [!important] PACER Classification: P — Procedural
> **Rationale**: 完整策略流程，属程序性知识

### Digest Actions

1. **选小词**：KD<29 + 10K 搜索量
2. **做厚**：首页解释清楚 + 5-10 个内页 + 回链
3. **等排名**：推广+外链，等小词进前三
4. **图大**：加兄弟词→父词，逐步扩展
