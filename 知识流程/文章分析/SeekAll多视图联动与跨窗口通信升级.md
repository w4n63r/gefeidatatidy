# SeekAll 多视图联动与跨窗口通信升级 - SeekAll 2.0 Architectural Evolution: Cross-Window State Sync & Tab Grouping

## Core Summary

> [!abstract] TLDR
> 复盘了哥飞自研桌面级聚合搜索 Chrome 插件 `SeekAll.ai` 经过 Google Web Store 官方严格审核后上线的重磅新版本升级与底层架构演进：系统公开了解除安全风控的“权限透明化声明”模板；全面打破了早期“最多只能选择 3 个搜索”的限制，升级为支持任意数量引擎并发；新增了适配单屏与垂直标签栏工作流的“Tab Grouping 标签页分组”模式；并攻克了“可跨窗口拖拽、实时同步追问输入、联动最大化/最小化与一键全量关闭”的跨窗口通信（Cross-Window State Synchronization）核心技术。
>
> - **插件权限透明化与用户安全信任构建**：
>   - **痛点**：安装高级 Chrome 扩展时浏览器易弹出安全风险提示，引发用户恐慌
>   - **解法**：在商店审核后台与官网详细公示每项权限的最小必要技术理由（如仅用于多窗口通信与状态存储，绝不上报用户本地私密数据），以公开透明消除安全顾虑
> - **SeekAll 架构与交互重大升级特性**：
>   1. **并发引擎数量解除限制**：由原先死板的 3 窗口升级为支持用户自定义任意数量（4~8 个）引擎同时检索
>   2. **双重呈现视图（自由切换）**：
>      - **多窗口平铺模式（Window Tiling）**：大屏多显示器最佳体验，多引擎并排展示
>      - **标签页分组模式（Tab Grouping）**：在当前窗口内自动创建 Tab Group，深度适配单屏轻薄本与垂直标签栏用户
>   3. **跨窗口通信浮窗（SeekAll Floating Bar）**：
>      - 浮窗按住可跨物理窗口自由穿梭
>      - 在任一窗口浮窗输入追问内容，其余所有窗口浮窗实时同步字符，回车实现全局并发追问
>   4. **窗口生命周期联动**：
>      - 最小化/最大化一个窗口，其余关联窗口自动依次恢复，避免繁琐手动唤起
>      - 浮窗右上角提供“一键关闭所有关联搜索窗口”快捷指令
