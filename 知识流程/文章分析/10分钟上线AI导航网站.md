# 10 分钟上线一个网站 - Launch a Website in 10 Minutes

## Core Summary

> [!abstract] TLDR
> 不买服务器、不找框架，**徒手 HTML + GitHub + Vercel** 就能上线一个可自动更新的网站；ChatGPT 帮你写页面，你的电脑就是"后台"。
>
> - **核心路径**：GitHub 建仓库 → 本地编辑 HTML 提交 → Vercel 绑定仓库/域名 → 自动 HTTPS → 提交即更新
> - **零成本启动**：域名可用闲置的，或直接用 Vercel 免费域名
> - **AI 辅助**：给 ChatGPT 网站名称和链接，让它生成 HTML 代码块填入列表
> - **适合新手**：不会 HTML 也行（写纯文本也能上线）；需要懂基本 GitHub 操作

### Digest Actions

核心是**程序性知识**——现在就动手，别攒着。

2. **写第一版**：本地写一个简单 HTML（或让 ChatGPT 生成），提交
