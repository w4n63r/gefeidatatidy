# BuiltWith：一人公司年入 1400 万美元 - $14M/Year with One Employee

## Core Summary

> [!abstract] TLDR
> BuiltWith.com 年收入 1400 万美元、只有创始人 1 个员工：**它卖的是"销售线索"**（a database of potential customers and leads）——爬取网站技术栈数据形成数据库，让销售找到潜在客户（相似站 ZoomInfo 市值 115.93 亿美元印证这条赛道）。
>
> - **秘密**：流量不高（170万/月）但客单价高（B2B 线索数据）
> - **用法**：搜 Mediavine/AdThrive/Raptive → 找到"能赚钱的利基站"→ 模仿
> - **技术**：爬虫爬 HTML → 分析技术栈 → 数据库（后端开发 2-3 年经验可做）
> - **启示**：数据类/线索类 B2B 生意客单价高；创始人是误打误撞切入

## Theme Analysis

### Theme 1: 线索生意的价值

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 客单价高 | B2B 线索数据贵 | "用户才愿意为BuiltWith付费" |
| 赛道验证 | 相似站市值证明需求 | ZoomInfo 市值 115.93 亿美元 |
| 流量≠收入 | 170 万流量却 1400 万收入 | 关键是"谁付费"而非"多少人看" |

> [!tip]- Top 3 Actionable Recommendations
> 1. **用 BuiltWith 找利基站**：搜 Mediavine/AdThrive/Raptive → 找到能赚钱的站 → 模仿（这是免费的选品工具！）
> 2. **想"数据类"生意**：把公开数据整理成对销售/决策有用的数据库，B2B 客单价高
> 3. **别只看流量**：评估生意看"谁付费、付多少"，不是 UV

### Theme 2: 技术可行性

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 技术不难 | 爬虫+分析技术栈 | "任何一个有两三年以上工作经验的后端开发人员都可以开发出来" |
| 切入偶然 | 创始人也误打误撞 | "并不知道这些数据可以卖钱" |

> [!warning]- 注意
> 线索/数据生意要解决"数据从哪来+合规"（爬虫要遵守 robots/ToS）；B2B 销售难度高于 C 端。
