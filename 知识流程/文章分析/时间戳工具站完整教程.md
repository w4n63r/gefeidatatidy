# 手把手做一个工具网站（timestamp 为例） - Build a Tool Site Step by Step

## Core Summary

> [!abstract] TLDR
> 以"时间戳工具"为例的**工具站完整教程**：分析竞品（学第一名）→ 查关键字密度与反链 → 找长尾词 → 选域名 → 规划 URL 结构（每个语言一个域名）→ 做页面（h1 做工具、长尾词 h2/h3 内页、密度 5%）→ sitemap 提交 → 动态页面让爬虫常来。
>
> - **竞争分析**：学第一名（外链多、多语言子目录），避开高权重站，找"内页/文章"类对手打
> - **关键字密度**：目标 ~5%（超过第一名的 4.1%）
> - **结构**：首页 h1=工具；每个长尾词一个 h2 内页（目录层级 /h2/ /h2/h3/）；内页链回首页
> - **多语言**：每个语言一个独立域名（不做子目录）
> - **动态化**：静态页爬虫爬完就不来了，要学头部站做动态页面

## Theme Analysis

### Theme 1: 竞争分析

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 学第一名 | 看它为什么排第一（外链/多语言） | "既然第一个站可以排第一……说明第一个站还是有两把刷子的" |
| 找软柿子 | 打内页/文章类对手，不打顶级站 | "有可能能够排到第四名，把这个给挤下去" |
| 权重信号 | 域名年龄+反链数 | 第一名反链 400 万、引荐域名 4900 |

> [!tip]- Top 3 Actionable Recommendations
> 1. **先分析再动手**：对目标词做"前 5 名分析"（外链/密度/域名年龄/是否内页），选能打的
> 2. **长尾词铺页面**：把下拉/相关搜索/竞品词收集去重，一个词一个内页
> 3. **密度控制在 ~5%**：别堆砌，用自然写作达到（第一名的 4.1% 就是参考）

### Theme 2: 结构与动态化

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| URL 层级 | h1 工具 + h2/h3 长尾目录 | "把所有的长尾词都变成h2……有层级关系的变成h2下的h3" |
| 内链回传 | 内页链回首页 | "所有的内页也需要到上一层级，直到首页的链接" |
| 爬虫常来 | 静态页不够，要动态页面 | "如果我想让搜索引擎爬虫经常来怎么办？可以……做动态页面" |

> [!warning]- 注意
> "关键字密度 5%"是 2023 年的经验值，现在更要紧的是"内容真正解决用户问题"（密度只是参考，别硬凑）。

## PACER Application

> [!important] PACER Classification: P — Procedural
> **Rationale**: 完整可执行教程，属程序性知识，按步骤照做

### Digest Actions

1. **选一个词**：挑一个有搜索量、竞争可打的关键词
2. **做竞品分析**：前 5 名表格（域名年龄/反链/密度/是否内页）
3. **搭结构**：h1 工具 + 3-5 个长尾 h2 内页，链回首页
4. **上线提交**：部署 + sitemap + GSC + 高权重社区发帖
5. **记录**：收录时间、排名变化
