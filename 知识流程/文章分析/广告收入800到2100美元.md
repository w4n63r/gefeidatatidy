# 广告收入 800→2000 美元/月 - Raising Ad Revenue from $800 to $2,100/Month

## Core Summary

> [!abstract] TLDR
> 一个图书下载站从月入 874 美元涨到 2100 美元的经验：**①重写前后端提速 ②站内 SEO 处理 ③广告位布局优化（一页 3 个广告位=谷歌推荐上限）**。
>
> - **提速**：老代码循环查库很慢，用 CodeIgniter 重写，改版保持 URL 一致
> - **SEO 结构**：每个页面类型定制 title/description/h1 格式（如"书籍名-站名-关键词"）；新增标签页/作者页/搜索页
> - **广告位**：首页/分类/详情/标签页都放满 3 个广告位
> - **结果**：上线第 2 天 UV/PV 暴涨（性能问题解决，搜索流量能接住）

## Theme Analysis

### Theme 1: 速度即收入

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 性能承接流量 | 慢站会丢掉搜索流量 | "有一部分用户发现点击搜索结果后需要好久才能打开页面，就直接关掉了" |
| 架构问题 | 循环查库=慢的根源 | "在循环里继续查询数据库，所以慢" |
| 改版保权重 | URL 结构必须与旧版一致 | "改版时，新版需要与旧版的url规划设计一致" |

> [!tip]- Top 3 Actionable Recommendations
> 1. **先修性能再谈优化**：页面加载速度是搜索流量承接的地基
> 2. **改版保 URL**：换框架/改版时保持 URL 结构，别丢已收录权重
> 3. **广告位放满 3 个**：谷歌推荐上限，别浪费流量

## PACER Application

> [!important] PACER Classification: P — Procedural
> **Rationale**: 可复制的优化清单，属程序性知识

### Digest Actions

1. **体检你的站**：页面打开快吗？循环查库？图片没 alt？
2. **定页面格式**：为首页/列表/详情/标签各定一套 title/description/h1 模板
3. **检查广告位**：是否每页都布局合理（上限 3 个）
4. **记录**：改版前后对比 UV/收入

### Reflection Questions

- [ ] 我的网站"速度"会不会在拖累承接搜索流量？
- [ ] 我的每个页面类型有没有统一的 title/h1 格式？
- [ ] 我有没有浪费流量（广告位太少/位置差）？
