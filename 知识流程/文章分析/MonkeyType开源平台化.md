# MonkeyType：开源+平台化 - Open Source + Platform = Viral Backlinks

## Core Summary

> [!abstract] TLDR
> monkeytype.com 1221 万/月、12500 Star、1700 个网站给了 8000 个外链：**因为开源+体验好→媒体报道+用户分享→扩散**；更妙的是它**变成了"平台"**——全世界打字爱好者来提交打字速度冲排行榜，为了冲榜常来测速。**GeminiProChat 与 MonkeyType 都因开源带来用户自发传播**。
>
> - **外链来源**：导航收录/评测/键盘测试/科技博客/记录新闻
> - **平台化**：冲榜机制让用户反复回来
> - **开源红利**：免费宣传+大量外链
> - **启示**：在线工具可以考虑开源

## Theme Analysis

### Theme 1: 开源+平台化

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 开源扩散 | 媒体+用户分享 | "因为是开源的……被很多媒体报道，也被很多的用户分享，于是带来了第一批扩散" |

> 3. **体验是扩散前提**：MonkeyType 靠"好用"被广泛引用
