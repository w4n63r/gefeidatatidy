# 给上线网站出 SEO 改造建议 - SEO Audit & Revamp Checklist

## Core Summary

> [!abstract] TLDR
> 老站 SEO 改造的总原则：**已经存在的 URL 一个都不要改**（被收录+外链指向不能丢）。然后两条路：**①挖需求加新页面（放老域名子目录）②找问题改老页面（TDK/内链/sitemap/canonical/H1H2H3）**。
>
> - **大原则**：已收录 URL 不改；新增页面放子目录=借老域名权重
> - **加新页面**：围绕潜在用户需求加工具/内容页
> - **改老页面**：TDK 规范、内链树形（首页→内页 ≤4 次点击）、sitemap、canonical（防重复收录）、H1/H2/H3 合理
> - **模板**：首页 title"站名-Slogan-关键词"；内页"功能-栏目-站名"

## Mind Map

```
老站SEO改造
├── 大原则：已存在URL不改（收录+外链）
├── 路1：挖需求加新页面（放子目录=借权重）
├── 路2：改老页面
│   ├── TDK：首页/栏目/内页 各一套格式
│   ├── 内链：树形，首页→内页≤4次点击
│   ├── sitemap：必须有
│   ├── canonical：防参数重复收录
│   └── H1×1 / H2×N / H3 层级
└── 效果：老页面优化 + 新页面增收录
```

## Theme Analysis

### Theme 1: 加新页面

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 借权重 | 新页面放老域名子目录 | "相当于做一个新网站，只不过新网站不使用新域名，而是放在老域名的子目录下" |
| 围绕用户 | 面向潜在用户需求加页 | "围绕着潜在用户群体，去尽量满足这些用户的潜在需求" |

> [!tip]- Top 3 Actionable Recommendations
> 1. **老站加新页**：用老域名权重做新需求页面（工具/内容）
> 2. **老页面体检**：TDK/内链/sitemap/canonical/H1H2H3 逐项检查
> 3. **URL 永不动**：已收录 URL 绝不改，改版靠加页面

### Theme 2: 改老页面清单

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| TDK 模板 | 每类页面一套格式 | 首页"站名-Slogan-关键词"；内页"功能-栏目-站名" |
| 内链结构 | 树形 + ≤4 次点击 | "尽量从首页到内页，不要超过4次点击" |
| canonical | 防参数 URL 重复收录 | "不管你用带任何参数的网址打开，搜索引擎都会认为是同一个页面" |
| H 标签 | 一页一个 H1 | "一个页面，只能有一个H1" |

## PACER Application

> [!important] PACER Classification: P — Procedural
> **Rationale**: 可执行的改造检查清单，属程序性知识

### Digest Actions

1. **体检你的站**：用清单过一遍（TDK/内链深度/sitemap/canonical/H标签）
2. **加 2 个新页面**：围绕目标用户需求，在子目录下做工具/内容页
3. **修问题**：按发现的问题逐项修（canonical 缺失/内链太深等）
4. **记录**：改造前后收录/排名变化
