# 一个简单工具月访问 2000 万 - A Dead-Simple Tool with 20M Monthly Visits

## Core Summary

> [!abstract] TLDR
> 一个"极简 Markdown 在线编辑器"（写文章→发布→得到一个链接），两个域名合计 1940 万月访问：**用户把它当工具，发布后把链接发到各处（外链/社交），流量几乎不走搜索引擎**——"简单工具+传播型链接"的模式。
>
> - **产品**：Markdown 编辑器+发布链接，功能极简（就这？）
> - **流量**：1940万/月，主要来自直接访问/外链/社交（搜索引擎很少）
> - **分析**：Semrush 导出外链 CSV → ChatGPT 分析 → 发现用户把链接发到哪
> - **启示**：简单工具如果"每次使用都产生一个可分享的链接"，自带传播
