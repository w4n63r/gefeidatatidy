# 千篇国学：谷歌百度双优化的内容结构 - Bilingual SEO via Smart Content Structure

## Core Summary

> [!abstract] TLDR
> 千篇国学站（qianp.com）谷歌百度都优化得好：89% 流量来自搜索、谷歌收录 484 万页/百度 193 万页。核心方法：**①用子域名做栏目（权重高于子目录）②"关键字重复不如用其它词解释关键字"——分门别类罗列内容，不堆砌关键词**。
>
> - **子域名栏目**：字典/词典/成语三个子站（子域名权重 > 子目录）
> - **分门别类**：成语按生肖/四季/数字/动物/植物/颜色/方位分类；按 AABB/ABAB 等结构分类
> - **原理**：分类词不含"成语"二字，但语义强相关=天然覆盖长尾
> - **案例参考**：2014 年公众号文章结构（成语大全→数字成语→动物名称成语→【鼠】…）

## Theme Analysis

### Theme 1: 内容结构即 SEO

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 子域名权重 | 子域名比目录权重高 | "因为子域名比目录的权重高，所以这个站用子域名来做栏目" |
| 语义相关 | 用分类词代替关键词重复 | "从含义上来讲，这些都是成语的不同分类，也就是跟成语有很大的相干性词语" |
| 规模效应 | 484 万收录页带来 89% 搜索流量 | 收录的网页真的能带来流量 |

> [!tip]- Top 3 Actionable Recommendations
> 1. **做内容站先定"分类体系"**：把你的主题按用户会搜的维度分门别类（时间/类型/场景/属性）
> 2. **用语义相关词铺内容**：别机械堆关键词，用"分类词/相关词"覆盖长尾
> 3. **栏目用子域名（可选）**：内容足够大时可拆子域名，权重更高

### Digest Actions

1. **选一个内容主题**：列出它的 5 个"分类维度"（如成语：生肖/结构/字数）
2. **设计页面树**：首页→分类页→具体条目页，每层语义相关
3. **对比**：你的页面是"堆关键词"还是"分类罗列"？
