# 发掘 Web 产品需求方法入门 - How to Discover Web Product Demands

## Core Summary

> [!abstract] TLDR
> 发掘需求就一句话：**看榜单、看数据、看别人都做了什么**。用 Similarweb 看竞品流量来源和搜索词、用爱站看关键词排名与搜索量、用 chinaz 查 SEO 难度——找到的每个关键词都可以单独注册域名做工具站。
>
> - **流程**：搜"在线工具"→找到 tool.lu → Similarweb 看流量来源(51%搜索)→ 找搜索词(时间戳/IP查询等)→ 爱站查这些词的排名与搜索量 → chinaz 查难度(<90 可做)
> - **选品标准**：纯前端可实现、有搜索流量、优化难度 <90、内页竞争可打
> - **案例**：DocHub.wiki 聚合优质文档，2 天上线，第 2 天 1000UV
> - **金句**：把散落的珍珠用线串起来也是需求

## Theme Analysis

### Theme 1: 数据化找需求

| Dimension | Insight | Supporting Evidence |
|-----------|---------|---------------------|
| 流量即需求 | 有搜索流量的词=有需求 | tool.lu 51% 流量来自搜索引擎 |
| 词即产品 | 每个搜索词可做一个站 | "这里的每个搜索词，都可以注册一个域名，单独做一个工具网站" |
| 难度过滤 | 难度分<90 才做 | "整体优化难度分为86分，不算太难，如果是90以上，那么趁早放弃" |

> [!tip]- Top 3 Actionable Recommendations
> 1. **本周实操**：用 Similarweb 查 3 个工具站，列出它们的搜索词清单
> 2. **难度过滤**：对候选词用 chinaz 查难度，>90 直接放弃
> 3. **从内页竞争切入**：前 50 名里首页少、内页多=机会（可把内页挤下去）

### Theme 2: 聚合型需求

### Digest Actions

1. **选一个方向**：在线工具/内容聚合/查询类
2. **跑工具链**：Similarweb→爱站→chinaz 走一遍，产出 5 个候选词
3. **做决策**：选 1 个"难度<90 + 有搜索量"的词
4. **记录**：写下你的"词→站"候选表
