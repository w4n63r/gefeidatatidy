# 1 小时被谷歌收录的操作复盘 - How a New Site Got Indexed in 1 Hour

## Core Summary

> [!abstract] TLDR
> 完整复盘"新站 1 小时被谷歌收录"：上午注册域名 → 写页面 → GitHub+Vercel 部署 → DNS 切 Cloudflare → 在 V2EX 发帖 → 爬虫 1 小时内来抓取。**发帖引荐是吸引爬虫的关键动作**。
>
> - **时间线**：11:09 注册域名 → 15:20 DNS 切 Cloudflare → 16:44 V2EX 发帖 → 17:56 收录快照
> - **关键**：V2EX 发帖（高权重）把爬虫吸引过来
> - **内容**：用搜索引擎+GPT 快速写好 Threads 介绍页（足够多内容）
> - **提醒**：收录只是第一步，有没有排名取决于页面 SEO 质量

> [!tip]- Top 3 Actionable Recommendations
> 1. **复刻这套时间线**：注册域名→备内容→部署→DNS稳定→去高权重社区发帖
> 2. **蹭热点上新站**：新平台/新词上线时（如当年的 Threads）快速做站，抢收录先发优势
> 3. **分清收录与排名**：被收录 ≠ 有排名，之后要补页面 SEO（标题/结构/内链）
